SLIDE 1: TITLE SLIDE

Title: AI-Assisted Protein Function Classifier
Subtitle: Predicting Broad Protein Functional Classes Using Machine Learning
Target Audience: Biomedical Engineering / Computational Biology Evaluation
Purpose: Broad computational protein function classification from primary amino-acid sequences

-------------------------------------------------------
SLIDE 2: INTRODUCTION & BIOMEDICAL MOTIVATION
-------------------------------------------------------
• Protein sequences in public databases (e.g., UniProt) continue to grow rapidly due to high-throughput sequencing.
• Experimental characterization of protein function in the laboratory is labor-intensive and time-consuming.
• A vast number of uncharacterized protein sequences require computational annotation.
• Computational Classification Role: Serves as a rapid, preliminary first-pass screening step to prioritize candidate proteins for detailed biological investigation.
• Key Premise: Sequence-derived physicochemical properties and amino-acid composition harbor predictive signals for broad functional roles.

-------------------------------------------------------
SLIDE 3: PROBLEM STATEMENT
-------------------------------------------------------
Problem:
"The growing disparity between available raw protein sequences and experimentally verified functional annotations creates a major bottleneck in biological research."

Key Challenges:
1. High volume of sequence data outpaces experimental annotation bandwidth.
2. Manual laboratory validation cannot scale to process whole-proteome sequence collections.
3. Computational prioritization tools are needed to categorize uncharacterized sequences into broad functional groups.

Solution Overview:
A machine-learning pipeline that maps primary amino-acid sequences to numerical physicochemical feature vectors to classify proteins into broad functional classes.

-------------------------------------------------------
SLIDE 4: OBJECTIVES & FUNCTIONAL CLASSES
-------------------------------------------------------
Primary Objective:
"Develop a machine-learning system that predicts broad protein functional classes from primary amino-acid sequences using sequence-derived features."

Specific Objectives:
1. Collect curated/reviewed protein sequences from UniProt REST API.
2. Build a balanced four-class protein dataset.
3. Extract 33 sequence-derived and physicochemical features.
4. Train and evaluate multiple machine-learning classifiers.
5. Develop and evaluate a Random Forest as the primary classifier.
6. Assess performance using cross-validation and an independent held-out test set.
7. Analyze model behavior using confusion matrices, ROC-AUC, and feature importance.
8. Demonstrate prediction on unseen protein sequences.

Four Broad Functional Classes:
┌──────────────┬────────────────────────────────────────────────────────┐
│ Class        │ Functional Description & Examples                      │
├──────────────┼────────────────────────────────────────────────────────┤
│ Enzyme       │ Catalyze biochemical reactions (e.g., Kinases, Proteases)│
│ Binding      │ Non-catalytic binding interactions (e.g., Receptors)   │
│ Regulatory   │ Control cellular processes (e.g., Transcription factors)│
│ Transporter  │ Facilitate molecular transport across membranes        │
└──────────────┴────────────────────────────────────────────────────────┘

SLIDE 6: DATASET & FEATURE ENGINEERING
-------------------------------------------------------
Dataset Summary (Curated UniProt Records):
• Total Final Samples: 1,119 proteins (Balanced dataset)
  - Enzyme:       280
  - Binding:      280
  - Regulatory:   280
  - Transporter:  279

Data Quality Filtering Metrics:
• Initial Records Fetched: 1,120
• Removed Duplicate Accessions: 0
• Removed Duplicate Sequences: 1
• Removed Unclear/Ambiguous Annotations: 60
• Final Dataset Samples: 1,119 (1,120 accessions, 1,119 unique sequences)

Feature Engineering (33 Sequence-Derived Features):
• Amino-Acid Composition (20 features): Relative frequencies of AA_A through AA_Y.
• Physicochemical & Sequence Features (13 features):
  - Sequence Length, Molecular Weight, Isoelectric Point (pI)
  - GRAVY Score (Grand Average of Hydropathy)
  - Compositional Fractions: Aromatic, Charged, Acidic, Basic, Hydrophobic, Polar, Cysteine, Proline
  - Hydrophobic Segment Information
• Purpose: Transforms raw amino-acid sequences into numerical representations for ML models.

SLIDE 8: INTERPRETABILITY & PREDICTION DEMONSTRATIONS
-------------------------------------------------------
Feature Importance Analysis:
• Top Impurity Features: GRAVY score (0.0851), Aromatic fraction (0.0622), Charged fraction (0.0601), Acidic fraction (0.0539), AA_F (0.0453).
• Top Permutation Features: GRAVY score (0.0379 ± 0.0092), AA_I (0.0165 ± 0.0066), Aromatic fraction (0.0152 ± 0.0166), Acidic fraction (0.0143 ± 0.0095).
• Scientific Interpretation: GRAVY score was the most useful feature for the Random Forest's decision-making in this dataset. Feature importance reflects model utility/predictive contribution and does not establish biological causation.

Prediction Demonstrations & Model Limitations:
1. Human Insulin (110 aa):
   - Predicted Class: Binding
   - Confidence Scores: Binding 37%, Enzyme 27%, Regulatory 24%, Transporter 12%
   - Interpretation: Model confidence represents a statistical probability estimate, NOT biological certainty.
2. Hemoglobin (142 aa):
   - Predicted Class: Enzyme (Enzyme 43%, Transporter 22%, Regulatory 19%, Binding 16%)
   - Limitation Insight: The model predicted Enzyme based on the sequence-derived feature representation, demonstrating that sequence-composition features alone can misclassify biologically distinct proteins.
3. Aquaporin:
   - Serves as a representative membrane water-channel protein test case for evaluating the Transporter class.
4. Edge Case Handling & Input Validation:
   - Prediction pipeline validates input sequences and rejects short/invalid amino-acid inputs to prevent misleading predictions.

SLIDE 9: LIMITATIONS & FUTURE WORK
-------------------------------------------------------
Model Limitations:
1. Evaluates four broad functional classes; does not provide fine-grained GO term annotations.
2. Relies solely on sequence-derived features without explicit 3D structural or active-site spatial information.
3. Biological functional overlap exists in nature (e.g., dual regulatory/binding proteins).
4. Enzyme classification exhibits lower recall (67.86%), revealing confusion with other functional classes.
5. Performance may vary on external datasets with differing class distributions.
6. Model probabilities represent statistical estimates, not biological certainty.
7. System is a computational research tool, NOT intended for clinical diagnosis, and requires experimental validation.

Future Research Directions:
• Expand classification granularity to fine-grained functional subcategories and additional protein families.
• Incorporate 3D structural descriptors (e.g., AlphaFold structure embeddings) and evolutionary conservation scores.
• Explore biological language model representations (e.g., ESM-2 / ProtBERT) and deep learning architectures.
• Improve classification performance on challenging classes such as Enzymes through specialized motif features.
